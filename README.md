# Palge

A production-oriented backend engineering project written in Go.

The goal of this project is to build a banking backend incrementally while applying real-world backend engineering practices.

> **Status:** In Development

---

## Current Features

- RESTful API
- Healthcheck endpoint
- JSON response helpers
- Structured logging
- HTTP timeouts
- Graceful shutdown
- In-memory banking API

---

## Planned Features

- PostgreSQL
- Authentication (JWT)
- Background Worker
- Redis
- Docker
- CI/CD
- Metrics & Observability
- Microservices

## Project Goals

- Learn backend engineering through hands-on implementation.
- Build production-oriented REST APIs using Go.
- Apply GitHub issues, milestones, and semantic commits.
- Evolve from a monolithic API into a distributed system.
